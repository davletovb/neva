# Hiyal

Hiyal is the home of the next-generation agent-based simulation and experimentation framework.

## Legacy Python implementation

The existing Python library, its documentation, tests, examples, packaging, and historical CI configuration are preserved under [`hiyal-python/`](hiyal-python/README.md).

The legacy project's GitHub Actions workflow is archived at [`hiyal-python/.github/workflows/ci.yml`](hiyal-python/.github/workflows/ci.yml). It is **inactive**: no workflow is installed at the repository-root `.github/workflows/` directory.

The previous Python implementation remains available for reference while the new architecture is developed. Run any Python tooling from within `hiyal-python/`.
